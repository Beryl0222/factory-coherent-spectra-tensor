# 异步采样的相干谱张量交付

频谱输入是两路振动计和一路触发辅助的合成时钟记录。 数据为本地合成。

- `data/capture.json` 保存采集原始内容。records 是交换记录，tensors 字段分开描述名称、类型、形状和值。整数索引从零开始，未指定闭合的区间均为左闭右开。
- `data/capacity.json` 保存制造端的容量、规模或分片条件。大尺寸是接口需考虑的使用规模。工作区计入新分配的解包、转换、归约、版本暂存及交接缓冲。调用方已有只读输入和已消费的输出不计入工作区，额外物化副本计入。

## 交换约定

所有触发时间转换成整数样本格，`offset_ticks` 加到数据块的本地起点，样本顺次。窗口从 `starts` 逐项开始，长度为 `nfft`。实值输入以资料中的 `window` 加窗，使用未归一的单边实 DFT。各通道 DFT 按响应复数值相除，响应为零或未列出表示该频点不可校正。功率归一为采样率乘窗系数平方和，非直流与非 Nyquist 频点折叠乘二。
采集块以 `(trigger, channel, id)` 区分，较高 `rev` 是对同一块的完整替代。同块同版的重发须有相同内容，若内容冲突则拒绝这条上报，保留已采入的内容。同一触发和通道的不同块在同一时格给出相同读数时只占一格，读数不一致时该时格不可用。不同触发的读数各自计算。示例的 `frozen_after_block` 是应答前已收到的上报条数，`frozen_request` 是当时已由训练端领用的触发、配对和频带。之后可查询当前结果，旧领用凭据仍对应当时的结果与支持窗。
对每对通道和每频段维护联合覆盖数，次数单位是有正频点权重且响应可校正的窗口。窗口内各可用频点贡献用频段权重累计，频段谱量分母为实际可用窗口频点权重和，两路自功率与互谱用同一分母。互谱为左通道变换乘右通道的复共轭。覆盖达到 `min_windows` 后且两路共同能量均大于零时允许交付相干特征。

## 读取资料

使用 Python 3.11。首次创建本地环境时安装锁定依赖。只读查看显示原始字段和张量尺寸。

```sh
python -m pip install -r requirements.txt
python caseio.py data/capture.json
python -m unittest discover -s tests -v
```

现有检查核对采集格式和所附数据的结构。
